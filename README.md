# SiteGuard

Construction site safety app: site map, safety reports, shift checks, lift checklist, permits,
vehicle inspections with HSE email reminders, machine guidance and a weekly summary.

**Live demo:** https://ghimiresabin580-dev.github.io/siteguard/

This website is a demo with sample data. The real SiteGuard screens (`app.js`) run in the
browser, and `demo.js` answers the calls the SiteGuard server would answer, so nothing is
saved and no emails are sent.

The full project (ASP.NET Core 8 server, web app, and iPhone/Android apps) is in
[`SiteGuard.zip`](SiteGuard.zip).

The demo site is drawn on the former Malmi airport in Helsinki. Map pictures: Esri (satellite)
and OpenStreetMap contributors (street map). Map library: Leaflet (BSD-2-Clause).
